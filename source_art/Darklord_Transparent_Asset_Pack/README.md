# Darklord Transparent Asset Pack

34 individually separated, fresh RGBA PNG assets for the void sigil character set.

Every PNG has a transparent alpha background and a 128 px transparent safety border so the files can be placed in a game without neighboring-sheet artifacts.

The supplied PDF and poster were treated as visual references. The reference posters/sheets are not included as production backgrounds. See `manifest.json` for dimensions, source image IDs, purposes, and QA metadata.
