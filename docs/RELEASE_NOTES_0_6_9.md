# Doodle Rumble v0.6.9 — Mac release candidate

The drawings move more like fighters now. All six playable doodles have more expressive packed-art motion, their selection previews fit, and the illustrated action paintings remain visible behind the character cutouts. H4CK3R and Dark lord now reveal their large attack art at the actual release moment, making the windup easier to read. Purple no longer holds a baked arrow after firing.

Round results keep the camera steady: the winner celebrates again, and a defeated fighter falls into the arena with stars above their head. We checked every character from both result spawns. The 30-second story ending was rebuilt with the updated art. Gameplay hitboxes, damage timing, save formats, the six-stage journey and Doodle Rally remain intact.

**Included:** a Universal Apple Silicon/Intel Mac app, the complete Godot 4.7.2 source project with all nine original transparent production packs, screenshots, build notes, validation logs and SHA-256 receipts. See [BUILD_STATUS.md](../BUILD_STATUS.md) and [TESTING_0_6_9.md](TESTING_0_6_9.md).

**Mac install note:** this machine has no Apple Developer ID certificate, so the app is locally ad-hoc signed and not notarized. A Mac receiving the ZIP may require **System Settings → Privacy & Security → Open Anyway**. Physical controllers, Intel execution and transferred first launch have not been verified here.
