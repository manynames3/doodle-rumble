# Doodle Rumble screenshots

These are native 1280×720 captures from the running Godot project, selected to show the public game's presentation rather than editor tooling or QA overlays. The fighter, combat and boss images were refreshed for v0.6.9 after the character-art motion pass.

| File | What it shows |
| --- | --- |
| `01-title-menu.png` | The cleaned intro poster and handwritten six-entry title menu. |
| `02-fighter-select.png` | Six selectable doodles with illustrated action paintings behind the transparent pack art and a large special preview. |
| `03-stage-select.png` | Six readable arena cards with hazards and the separate stage page. |
| `04-combat-desktop-dojo.png` | Orange's spin against Blue in Desktop Dojo, with compact ink HUD, platform scenery and the new moving pack art. |
| `05-round-result.png` | A fixed-camera result: Dark lord celebrates while Red lies on the floor with orbiting stars. |
| `06-desktop-dojo-motion.png` | Desktop screens typing/drawing and paper-desk ambience in motion. |
| `07-block-quarry-motion.png` | Quarry crane, cargo and bird ambience in motion. |
| `08-glitch-core-motion.png` | Glitching monitors, neon signage and portal pixels in motion. |
| `09-transparent-fighter-selection.png` | Green's packed lightning special in the large preview, with all six illustrated character cards. |
| `10-transparent-fighter-combat.png` | Purple's packed guard facing Red's hammer in a live Desktop Dojo match scene. |
| `11-dark-lord-pack.png` | Dark lord's released void-sigil art in the final stage, distinct from its earlier tell. |
| `12-h4ck3r-pack.png` | H4CK3R's released system-scan art in Neon Switchyard, distinct from its earlier tell. |
| `13-pac-man-pack.png` | Pac-Man's new bite art in Arcade Afterglow. |

The private original drawing and versioned QA captures stay out of the public repository. The nine transparent production packs are retained under `source_art/`, with optimized runtime copies under `game/assets/character_art/`.
