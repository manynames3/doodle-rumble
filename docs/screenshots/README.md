# Doodle Rumble screenshots

These are native 1280×720 captures from the v0.6.x Godot project, selected to show the public game's presentation rather than editor tooling or QA overlays.

| File | What it shows |
| --- | --- |
| `01-title-menu.png` | The cleaned intro poster and handwritten six-entry title menu. |
| `02-fighter-select.png` | Six selectable doodles, illustrated special previews and difficulty choices. |
| `03-stage-select.png` | Six readable arena cards with hazards and the separate stage page. |
| `04-combat-desktop-dojo.png` | A live Orange versus Blue round with compact ink HUD, platforms and damage-ready combat framing. |
| `05-round-result.png` | A fixed-camera round result: the winner celebrates while the loser is down with stars. |
| `06-desktop-dojo-motion.png` | Desktop screens typing/drawing and paper-desk ambience in motion. |
| `07-block-quarry-motion.png` | Quarry crane, cargo and bird ambience in motion. |
| `08-glitch-core-motion.png` | Glitching monitors, neon signage and portal pixels in motion. |

The raw supplied reference folder and versioned QA captures stay out of the public repository. Runtime art is included under `game/assets/`; provenance and licenses are documented in [`docs/ASSET_PROVENANCE.md`](../ASSET_PROVENANCE.md).
